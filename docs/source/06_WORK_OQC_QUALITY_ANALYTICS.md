# WORK_OQC_QUALITY_ANALYTICS

**Work Type:** 수행영역 Living Context  
**관리 대상:** 최신 OQC 비교 / 통계 / 이상탐지 / 데이터 신뢰성 검증  
**상태:** 요구사항 확정 / 통계 Rule 상세값 미설정  
**Core:** `02_OQC_WORK_CORE.md`

---

## 1. 목적

최신 OQC를 단순 PASS/FAIL로 보지 않고, 같은 모델의 검증된 누적 DB와 비교하여 다음을 자동 판단한다.

- 현재 Spec 적합 여부
- 과거 대비 평균·산포·공정능력 변화
- 이상 시작시점과 지속성
- 특정 Point·Cavity·생산일의 반복 편향
- 누락·수식오류·반복값 등 데이터 신뢰성 Risk
- 동반 변화 검사항목과 추가 확인정보

사용자가 원본 OQC를 다시 열어 어느 값이 이상한지 찾아야 하는 구조를 허용하지 않는다.

---

## 2. 기본 비교순서

최신 OQC 입력 시 항목별 비교순서:

1. 최신 Lot 자체 Spec 판정
2. 동일 조건 최근 N Lot
3. 동일 조건 전체 누적
4. 다른 조건을 포함한 장기 Reference

### 우선 비교조건

가능한 경우 다음 조건이 같은 데이터를 먼저 사용한다.

- 모델
- 부품
- 검사항목
- 업체
- Spec Revision
- 측정방법
- 생산단계
- 생산공장 / Line
- 금형 / Cavity

조건이 다른 데이터는 삭제하지 않고 장기 Trend Reference로 구분한다.

---

## 3. 기준 데이터 축적 중 처리

신규 모델·신규 업체·변경 후 구간처럼 비교 데이터가 부족하면 억지로 Trend 이상이나 공정능력 결론을 만들지 않는다.

- Master Spec 절대 판정은 즉시 수행
- 데이터 충분성 부족은 `기준 데이터 축적 중`으로 표시
- Cpk·UCL/LCL·업체 우위는 참고 또는 산출불가
- 유사모델 데이터는 Reference로만 표시

## 4. 검사항목 유형별 분석

### 4.1 연속형 치수·평탄도·조도·함수율·강도

- 평균
- Min / Max
- Range
- 표준편차
- Spec Margin
- Cp/Cpk 또는 Pp/Ppk
- Trend
- UCL/LCL
- Outlier

### 4.2 일방향 관리항목

예: 함수율 상한, BCT 하한.

- 상한 또는 하한 Margin
- 최근 악화방향
- 한계 접근률
- 평균과 산포
- 공정능력 또는 적합률

### 4.3 외관

- OK / NG
- 검사수량
- NG 수량 / NG율
- OQC에 기입된 불량유형
- 신규 불량유형
- 반복 불량유형

사진은 분석하지 않는다.

### 4.4 다중 Point·좌표

- Point별 Trend
- Point별 평균·산포
- 특정 Point 반복 편향
- X/Y 좌표 분리
- 전체 평균은 정상이나 특정 위치만 열세인 경우 별도 이상

### 4.5 Cavity

- Cavity별 Sample 대표성
- Cavity별 평균·산포·Cpk
- 금형 전체 정상 / 특정 Cavity 지속 열세 구분
- 정상 Cavity 대비 편차

Cavity 정보가 없으면 추정하지 않는다.

---

## 5. Spec 판정과 Trend 판정 분리

### Spec 판정

- Master Spec 기준 PASS / FAIL
- 업체 기재 PASS/FAIL과 재계산 결과 비교
- OQC Spec과 Master Spec 불일치

### Trend 이상

Spec 안쪽이어도 다음이면 이상으로 올린다.

- 평균 Shift
- 산포 확대
- Cpk 하락
- 최근 연속 악화
- UCL/LCL 이탈
- 특정 Point·Cavity 편향
- Spec 한계방향 연속 접근

화면에는 `규격 판정`과 `추세 이상 판정`을 별도로 보여준다.

---

## 6. 누적통계와 공정능력

### 6.1 산출조건

Cp/Cpk/Pp/Ppk는 다음을 만족할 때만 정식 표시한다.

- 충분한 Sample 수
- 동일 Spec Revision
- 비교 가능한 측정방법
- 생산단계가 혼합되지 않음
- 공식 `VALID` 데이터

조건이 부족하면 `산출 불가` 또는 `참고 수준`으로 표시한다.

### 6.2 비교

- 최신 Lot
- 최근 5 Lot 또는 설정 N Lot
- 장기 누적

을 함께 본다.

Cpk가 낮아진 원인을:

- 평균 Shift
- 산포 증가
- 단일 Outlier 영향

으로 분리한다.

### 6.3 Spec Limit vs Control Limit

- **Spec Limit:** 도면·승인 기준, 절대 판정
- **Control Limit:** 안정된 실제 공정분포 기준

UCL/LCL은 공식 `VALID` 데이터와 동일 비교조건으로 계산한다.
데이터가 충분하지 않으면 생성하지 않는다.

---

## 7. 최신 OQC 요약

최신 Lot은 전체 통계보다 `무엇이 달라졌는지`를 먼저 보여준다.

예:

- 전체 42개 항목 중 확인 필요 3개
- 포켓 폭: 최근 5 Lot 대비 평균 +18%, Spec 내
- 평탄도: 산포 1.6배 확대
- 홀 위치 P2: 과거 동일값 반복 의심

각 문장은 해당 데이터·그래프·Sample로 직접 연결한다. 당시 판단이력에는 전체 그래프 Snapshot 대신 대상 LOT·DB Version·이상항목·근거·사용자 조치만 가볍게 저장한다.

---

## 8. 이상 시작점과 지속성

최신 이상이 발견되면 과거 DB에서 자동으로 다음을 찾는다.

- 최초 Shift 시점
- 산포 확대 시작 Lot
- 연속 악화 Lot 수
- 일회성 / 지속 / 재발
- 4M·금형수정·Spec 변경과의 시간관계

예:

- 8/15 급격한 악화
- 8/08 평균 Shift 시작
- 8/01 산포 확대 시작
- 7월까지 안정

---

## 9. 검사항목 간 동반 변화

이상 항목과 같은 시점에 움직인 다른 항목을 찾는다.

예:

- 평탄도 악화
- 적재높이 증가
- 특정 포켓 치수 Shift

동일 시점부터 함께 움직이면 `동반 변화`로 묶어 보여준다.

상관관계가 있다고 원인으로 확정하지 않는다.
AI 설명에는 `연관 가능성`으로 표현한다.

---

## 10. 생산일·작업조 Sub-group

Trend 기본시간축:

1. 생산일
2. 생산일이 없으면 검사일
3. 둘 다 없으면 수신일

출하 Trend는 실제 출하일을 사용한다.

같은 LOT이 여러 생산일이면:

- LOT 전체
- 생산일별 Sub-group

을 모두 본다.

LOT 전체 평균이 정상이어도 특정 생산일만 Shift하면 별도 이상으로 올린다.
작업조 정보가 있으면 추가 비교축으로 사용하되 필수 요구하지 않는다.

---

## 11. Point·Cavity 반복 편향

### Point

- 특정 Point가 여러 Lot에서 같은 방향으로 치우침
- 최신 Lot에서 추가 악화
- 전체 평균에 가려진 위치별 Risk

을 별도 표시한다.

### Cavity

- 금형 전체 Cpk 정상
- 특정 Cavity Cpk 지속 열세

이면 `Cavity 지속 편향` Issue 후보로 올린다.

예:

- 전체 Cpk 1.72
- Cavity #3 Cpk 1.29
- 최근 8 Lot 중 7 Lot 동일 방향

---

## 12. Sample·Point·Cavity 누락

- 기준 Sample 10개인데 8개만 있음
- Cavity별 5개 기준인데 특정 Cavity 1개 또는 0개
- 기존 Point가 이번 OQC에서 빠짐
- 신규 Point가 추가됨

을 정확히 구분한다.

검사주기가 있는 항목은 `05_WORK_OQC_MASTER_CONFIG.md`의 Window 기준으로 누락을 판단한다.

---

## 13. 값·단위·형식 이상

자동 확인:

- 빈칸
- `-`, `N/A`, `OK`가 숫자영역에 입력
- 단위 변경
- 실제 저장값 정밀도 변화
- 수식과 상수 혼재
- 일부 셀만 다른 형식
- 날짜·LOT 형식변경

엑셀 표시자릿수만으로 정밀도 저하를 판단하지 않는다. 실제 저장값 자체의 기록정밀도가 낮아진 것으로 확인되면 값과 Spec 판정은 보존하되, 확인 전에는 기존 고정밀 데이터와 섞어 Cpk·σ·UCL/LCL을 재계산하지 않는다. 표시형식 문제로 확인되면 원래 저장값으로 정상 연결한다.

## 14. 수식 및 판정 재검증

프로그램이 Raw Measurement로 다시 계산한다.

- 평균
- Min / Max
- 판정
- 누적수량 산술

업체 계산과 다르면:

- 항목
- Sheet / Cell
- 업체값
- 재계산값
- 차이

를 보여준다.

---

## 15. 데이터 신뢰성 탐지

### 15.1 Exact Duplicate

날짜·LOT가 다른데 Sample Vector가 전체 동일.

### 15.2 Partial Duplicate

10개 중 8~9개가 같은 순서로 동일.

### 15.3 반복주기

`10.1 / 10.2 / 10.1 / 10.2`처럼 비정상적 규칙 반복.

### 15.4 다수항목 동시 복제

이전 OQC와 여러 검사항목의 전체 Sample 배열이 동일.

### 15.5 소수점 패턴

여러 날짜에 동일한 소수점 조합이 비정상적으로 반복.

### 15.6 수정본 방향성

- NG → PASS
- 공차 완화
- 측정값이 Spec 안쪽으로 수정
- 누적출하량 수정

### 표시 원칙

`데이터 신뢰성 의심`만 띄우지 않는다.

예:

`외형높이 / 8월 Lot 12 / Sample 3~10이 7월 Lot 08과 소수점 3자리까지 완전 동일`

처럼 비교대상과 일치범위를 직접 보여준다.

### 상태 원칙

- 의심만으로 자동 제외하지 않음
- `SUSPECT`로 공식 기준선에서 제외 가능
- 사용자 확인 후 `VALID` 또는 `EXCLUDED`
- 확인된 허위와 의심을 구분

---

## 16. Outlier

Outlier를 자동 삭제하지 않는다.

표시내용:

- 실제값
- Spec Margin
- 누적분포상 위치
- 발생 Point / Cavity / 생산일
- 공식 Cpk
- Outlier 1개를 제외했을 때의 참고 Cpk

`Outlier 제외 Cpk`는 원인구분 참고값이며 공식 Cpk가 아니다.

### 반복성

- 한 Lot 단발
- 같은 Point 반복
- 같은 Cavity 반복
- 특정 업체·생산구간 집중
- 최근 빈도 증가

를 구분한다.

---

## 17. 사용자 예외판단 학습

프로그램이 Trend 이상으로 올렸으나 사용자가 공정특성상 정상이라고 확인한 경우:

- `AI/Rule 이상판정 → 사용자 정상 또는 예외 승인` 이력 저장
- 승인사유 기록
- 이후 동일 조건·동일 패턴의 불필요한 경고강도 조정 가능

단, Master Spec 이탈·필수항목 누락·공차 불일치 같은 절대 Gate는 예외학습으로 무시하지 않는다.

---

## 18. 통계 제외와 복구

잘못된 값이 확인되면 삭제하지 않고 `EXCLUDED` 처리한다.

필수 기록:

- 제외사유
- 처리일
- 처리자
- 원본값
- 대체값 존재여부

복구 가능.

제외·복구 시 해당 모델·부품·업체·검사항목만 증분 재계산한다.

---

## 19. 이상 원인 후보와 추가정보

원인 후보 분석은 이상 Issue가 생성된 항목에만 실행한다.

사용 가능한 정보 예:

- 동반 변화 항목
- 생산일 / 작업조
- 금형 / Cavity
- 생산공장 / Line
- 함수율 / BCT 등 관련 품질값
- 4M·Spec·측정방법 변경

OQC에 없는 정보를 추정하지 않는다.

예:

- 특정 Point 반복 Shift → Cavity / 금형 위치 정보 확인 필요
- Lot 전체 평균 급변 → 원재료 Lot / 생산조건 변경 여부 확인 필요
- 측정방법 변경과 동시 Shift → 방법 영향 확인 필요

AI는 원인을 확정하지 않고 근거와 가능성을 제시한다.

---

## 20. 개선 전·후 분석

업체가 개선했다고 기재한 것만으로 개선 인정하지 않는다.

실제 데이터에서:

- Cpk 변화
- 평균 Shift 정상화
- 산포 감소
- 이상 재발 여부
- 연속 정상 Lot
- 개선 후 정상 출하수량

을 비교한다.

개선 효과는 업체평가 가점보다 `08_WORK_OQC_ISSUE_SUPPLY_STABILITY.md`의 공급 안정성 판단에 우선 활용한다.

## 21. 부하 원칙

신규 Lot 입력 시 해당 항목만:

- Cache Update
- 최근 N Lot Update
- Rule 평가
- 관련 Issue Update

한다.

다음은 On-demand:

- 최신/최근/전체 분포 중첩
- 기간 A ↔ B 전수 비교
- 신규 Spec 시뮬레이션
- 전체 과거 재판정

---

## 22. 현재 판단

### 확정

- Spec 이탈과 Trend 이상을 분리한다.
- 전체 누적과 최근 N Lot을 동시에 본다.
- 데이터 신뢰성 의심의 정확한 비교근거를 보여준다.
- Outlier·의심값을 자동 삭제하지 않는다.
- Point·Cavity·생산일 Sub-group 이상을 전체 평균과 분리한다.

### 미확정

- 최소 Sample 수
- Cpk 관리기준
- Shift·산포·Outlier Rule Threshold
- Duplicate 의심 Threshold

기본값은 구현 시 제안하되 모델·항목별 수정 가능하게 한다.

---

## 23. Gate

### Analytics Gate

- 최신 OQC와 동일조건 최근 N Lot 비교
- Spec 재판정
- 평균·산포·Cpk 계산 검증
- 이상항목 우선정렬
- Raw Sample까지 Drill-down

### Trust Gate

- Exact / Partial Duplicate Test
- 수정본·NG→PASS Detection
- 의심대상과 비교근거 직접 표시
- 사용자 확인 전 자동제외 금지

---

## 24. Resume Point

대표 OQC와 과거 3~5건을 확보한 뒤:

1. 연속형 항목 통계 계산
2. 업체 판정 교차검증
