# WORK_OQC_SUPPLIER_EVALUATION

**Work Type:** 수행영역 Living Context  
**관리 대상:** 업체 품질평가 / 데이터 신뢰성 / 이원화 비교 / 품질기준 공급비중 판단근거  
**상태:** 평가축 확정 / 세부 가중치 미설정  
**Core:** `02_OQC_WORK_CORE.md`

---

## 1. 목적

동일 모델·부품을 공급하는 업체의 실제 품질수준과 OQC 관리 신뢰성을 객관적 누적 데이터로 비교한다.

업체평가는 최신 OQC 한 건이나 단순 불량건수 순위가 아니다.

- 공정 실력
- 장기 안정성
- 최근 변화
- 반복 이상
- 정기검사·OQC 근거
- 데이터 신뢰성
- 실제 공급 Exposure

를 함께 본다.

---

## 2. 평가단위

기본:

**모델 → 부품 → 업체**

추가:

- 업체 전체 종합평가
- 생산공장 / Line별 품질수준

금형·Cavity는 원인분석과 취약점 필터로 사용하며 기본 Dashboard 계층을 불필요하게 깊게 만들지 않는다.

---

## 3. 공식 평가축

1. **공정능력**
2. **품질 안정성**
3. **Spec 이탈 / 반복이상 / 재발**
4. **정기검사 준수**
5. **OQC 데이터 신뢰성**
6. **OQC 제출기준 및 품질근거 Coverage 준수**
7. **누적 OQC 정상 출하실적**

현재 자동평가에서 제외:

- 업체 답변속도
- Action Due 준수시간

실제 개선성과는 점수 가점보다 공급 안정성 전망에 우선 반영한다.

---

## 4. 생산단계 반영

공식 평가점수는 정상 양산 구간을 중심으로 계산한다.

별도 표시:

- 초기 생산 실적
- 안정화 속도
- 4M 후 재안정화
- 재공급 검증
- 현재 생산상태

초기 품질 시행착오는 정상 양산 장기점수와 같은 비중으로 계속 감점하지 않는다.

단, 다음은 생산단계와 무관하게 반영한다.

- 허위 OQC
- Spec 임의변경
- NG 은폐
- 중대 데이터 신뢰성 문제

---

## 5. 최근과 장기실적

평가화면은 최소 다음을 분리한다.

- 최근 1개월
- 최근 3개월
- 연간 / 장기 누적
- 현재 품질수준
- 장기 신뢰도
- 개선 / 유지 / 악화 방향성

장기 실적이 좋다고 최근 악화가 묻히지 않는다.

---

## 6. 공정능력 평가

항목별로:

- Cpk/Ppk
- 평균 Shift
- 산포
- Spec Margin
- 기간별 추세

를 본다.

같은 Spec을 만족해도:

- 업체 A Cpk 2.0, 산포 작음
- 업체 B Cpk 1.35, Spec 근처

이면 A의 공정능력이 우수하다.

Cpk 숫자만으로 평가하지 않고 데이터양·조건·생산단계를 함께 본다.

---

## 7. 이상·재발 평가

성격에 맞는 모수를 사용한다.

- 치수 Shift / Cpk 저하 → 이상 Lot 비율
- 외관 NG → 검사수량 대비 NG율
- Spec 이탈 → Spec 이탈 Lot 비율
- 출하 Risk → 영향 가능 출하수량
- 데이터 신뢰성 → 출하수량과 무관한 중대도

모든 이상을 하나의 출하불량률로 통합하지 않는다.

---

## 8. 공급량 보정

단순 절대건수 비교를 금지한다.

예:

- 업체 A 100 Lot / 50만 EA / 이상 3건
- 업체 B 10 Lot / 3만 EA / 이상 1건

평가 시:

- Lot당 발생률
- Spec 이탈 Lot 비율
- 검사수량 대비 NG율
- 출하 Exposure
- 데이터 충분성

을 함께 본다.

---

## 9. 평가 신뢰도

평가점수와 별도로 신뢰도를 표시한다.

기준:

- 평가기간
- Lot 수
- 출하수량
- 비교 가능한 CTQ 수
- 최신 정기검사
- Coverage

데이터가 적은 업체는 점수가 높아도 `참고점수`로 두고 정식순위에 바로 반영하지 않는다.

---

## 10. OQC 데이터 신뢰성

### 중대도

- 경미: 단순 오타·표기실수
- 주의: 반복값·복붙 의심
- 중대: 측정값 수정, NG→PASS, 공차 임의변경
- 최중대: 허위 데이터 확인

평가에는 건수·중대도·반복성을 반영한다.

### 의심과 확인

- `SUSPECT`: 의심, 사용자 확인 전
- `CONFIRMED`: 허위·조작 확인

의심만으로 최중대 Penalty를 확정하지 않는다.

---

## 11. 수정본 신뢰성

수정본 발생 자체를 모두 감점하지 않는다.

- 단순 문구·오탈자 → 영향 거의 없음
- 측정값·판정·Spec·출하수량 수정 반복 → 신뢰성 저하
- NG→PASS·공차완화 방향 반복 → 중대 Risk

수정내용의 중요도와 방향성을 본다.

---

## 12. 사건 중복감점 방지

하나의 사건이:

- 제출기준 미준수
- Spec 불일치
- 데이터 신뢰성

여러 항목에 걸려도 풀 Penalty를 중복 적용하지 않는다.

`원인 사건 1건`으로 묶고:

- 주 평가항목
- 연관 영향
- 총 Penalty 상한

을 적용한다.

반복사건은 추가 감점 가능하다.

---

## 13. 허위 데이터 Hard Gate

허위가 확인되면 다른 품질점수가 좋아도 종합등급 상한을 둔다.

예:

- 계산점수 A
- 허위 OQC 확인
- 공식 최대등급 B

상한 해제는 시간이 지났다고 자동 처리하지 않는다.

### 신뢰성 회복 후보

- 정상 OQC 일정기간 누적
- 반복패턴 이상 없음
- Spec·출하수량 불일치 없음
- 주요 관리항목 정상

을 만족하면 후보로 올리고, 최종 해제는 사용자 승인.

과거 중대 신뢰성 이력은 해제 후에도 보존한다.

---

## 14. 정기검사·제출기준·Coverage

평가에 반영:

- BCT 등 주기 준수
- 필수항목 누락
- Sample 부족
- 중요 CTQ 누락
- 승인 없는 Spec 변경
- 출하 OQC Coverage
- 품질근거 미완성 출하 반복

단, 실제 공급하지 않은 기간은 미제출 감점하지 않는다.

제품 품질과 OQC 운영 준수는 분리해서 보여준다.

---

## 15. 개선성과의 위치

- 문제 예방·장기 안정 > 문제 발생 후 개선
- 개선됐다는 업체 주장만으로 가점 없음
- 개선 전후 데이터와 정상출하실적을 확인
- 개선효과는 향후 공급 안정성 전망에 우선 사용
- 장기 정착 후에는 현재 품질수준으로 흡수

업체평가에 별도 큰 가점을 주지 않는다.

---

## 16. 이원화 업체 직접비교

같은 모델·부품을 계속 공급하는 업체 간 비교.

### 비교조건

정면 비교는 가능한 경우 다음이 같은 공통항목으로 한다.

- Spec Revision
- 측정방법
- 생산단계
- 검사항목 정의

업체별 추가 검사항목은 별도평가로 남기고, 더 많이 검사하는 업체가 불리해지지 않게 한다.

### 중요 CTQ

공통항목을 단순 평균하지 않고 중요 CTQ를 더 크게 반영한다.
중요 CTQ 열세가 전체 평균에 묻히지 않는다.

---

## 17. CTQ별 업체 우위

항목별 결과:

- 업체 A 우위
- 동등
- 업체 B 우위
- 판단 보류

판정요소:

- Cpk 또는 항목특성별 지표
- 차이 크기
- 지속성
- Lot 수
- 출하수량
- 생산단계
- 판단 신뢰도

예:

- A Cpk 1.71 / B 1.68 → 동등 가능
- A 1.95 / B 1.32, 지속 → A 우위
- B 3 Lot만 존재 → 판단 보류

---

## 18. 항목유형별 비교 Logic

- 치수: Cpk, 평균, 산포
- BCT: 평균강도, 하한 Margin, 추세
- 함수율: 상한 Margin, 변동성
- 외관: NG율, 반복유형
- 다중 Point: 위치별 편향
- Cavity: 특정 Cavity 열세

기준은 항목별 설정 가능하다.

---

## 19. 현재 품질과 장기 품질

이원화 비교화면에서:

- 현재 경쟁력: 최근 정상양산 중심
- 장기 신뢰도: 장기 Lot·출하실적
- 방향성: 개선 / 유지 / 악화
- 현재 생산상태
- 공급 안정성

을 함께 보여준다.

예:

- 업체 A: 평가 A / 정상양산 / 안정
- 업체 B: 평가 A / 4M 후 재안정화 / 관찰

---

## 20. 생산공장·Line

같은 업체라도 공장·Line이 다르면 공식 기준선과 공급 안정성을 분리한다.

업체 전체평가에는 종합 가능하되 실제 품질차이를 가리지 않는다.

정보가 OQC에 없으면 별도 필수화하지 않는 한 추정하지 않는다.

---

## 21. 금형·Cavity

금형·Cavity별 취약점은 해당 모델·부품 공급 안정성에 우선 반영한다.

전체 업체평가 감점은:

- 반복성
- 영향범위
- 중요 CTQ
- 개선여부

를 보고 결정한다.

---

## 22. 공급비중 검토 근거

프로그램은 품질관점에서만 다음을 제시한다.

- 공급 확대에 유리
- 현 수준 유지
- 품질 안정화 전 비중확대 주의

가격·납기·생산능력을 섞어 `70:30` 같은 최종 비율을 자동결정하지 않는다.

---

## 23. 평가점수와 가중치

가중치는 관리자 설정.

예시 평가축은 확정됐지만 숫자배분은 실제 사용자가 설정한다.

중요 원칙:

- 데이터 신뢰성 최중대 Hard Gate
- CTQ Hard Gate
- 사건 중복감점 방지
- 생산초기와 정상양산 분리
- 최근 악화를 장기실적이 가리지 않음

---

## 24. 평가 확정과 사후 재평가

월간·분기 평가:

- 프로그램 자동계산
- 사용자가 평가 보류 / 예외 / 코멘트 가능
- `평가 확정` 후 과거점수 자동변경 금지

사후 중대사실 발견 시:

- 최초 확정점수 보존
- 사후 확인사항 표시
- 재평가점수 별도계산
- 장기평가에는 재평가 반영

예:

`최초 88점 → 사후 재평가 72점`

---

## 25. 업체 전체 종합평가

모델·부품별 평가를 유지하면서 업체 전체 종합을 제공한다.

한 모델이 물량이나 항목 수 때문에 종합점수를 과도하게 지배하지 않도록 별도 종합 Logic을 둔다.

기간별 등급변화와 원인을 보여준다. 평가축·감점·CTQ 우위를 누르면 해당 기간의 실제 모델·부품·검사항목·Issue·OQC 측정값까지 Drill-down할 수 있어야 한다.

---

## 26. Export

월간·분기·연간 업체 품질평가표를 당사 표준 Excel로 Export한다.

포함 가능:

- 총점 / 등급 / 평가 신뢰도
- 현재 생산상태
- 공급 안정성
- 평가축별 점수와 근거
- CTQ별 업체 우위
- 신뢰성 Issue
- 전월·전분기 변화원인
- 모델·부품 상세

---

## 27. 현재 판단

### 확정

- 업체평가는 품질 실력과 관리 신뢰성을 같이 본다.
- 대응속도는 자동평가에서 제외한다.
- 허위 확인은 중대 Hard Gate다.
- 이원화 비교는 공통 비교가능 항목과 CTQ 중심이다.
- 데이터 부족업체는 참고점수로 둔다.

### 미확정

- 평가축 가중치
- 등급구간
- 신뢰성 회복기간
- 직접비교 우위 Threshold

---

## 28. Gate

### Evaluation Gate

- 정상양산 데이터 중심 평가
- 최근·장기 분리
- 평가신뢰도
- 사건 중복감점 방지

### Trust Gate

- 의심 / 확인 구분
- 등급상한
- 회복후 과거이력 유지

### Dual Source Gate

- 비교가능 공통항목 선정
- CTQ 우위 / 동등 / 보류
- 데이터양·출하량 반영

---

## 29. Resume Point

품질분석과 출하 DB가 확보된 뒤:

1. 평가축별 정량 Indicator 정의
2. 사용자와 가중치·Hard Gate 확정
3. 업체 A/B Dummy Data 비교
4. 허위·수정본·Coverage Event 중복감점 Test
5. 월간평가 확정·사후재평가 이력 Test
